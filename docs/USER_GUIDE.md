# 详细使用指南

[返回项目说明](../README.md)

本文介绍平台的完整管理与编辑能力。后台支持账号与角色权限，演示账号、启动方法及部署配置见项目说明。

多项目文档平台。每个项目都是完整的文档中心：产品大类 → 产品列表 → 具体产品 → 多级文档分类 → 文档。

## 本地运行

```sh
npm install
npm run dev
```

- 后台：`http://localhost:4000/admin`
- 项目入口列表：`/`
- 独立项目首页：`/projects/{项目标识}`
- 产品文档：`/projects/{项目标识}/products/{产品标识}`
- 文档阅读：`/projects/{项目标识}/products/{产品标识}/docs/{文档ID}`
- 产品动态：`/projects/{项目标识}/products/{产品标识}/updates`

生产模式：`npm run build` 后 `npm start`。独立开发预览：`NEXT_DIST_DIR=.next-dev npx next dev -p 4001`。

## 界面

前台参考火山引擎的产品目录与文档导航布局。后台使用 Arco Design React 的菜单、表格、搜索筛选、表单、按钮与弹窗；前后台共用 Arco 色彩变量。页面布局样式位于 `src/app/document-portal.css`，后台主题位于 `src/app/admin/arco-theme.css`。

## 管理流程

1. 新建项目，填写名称、公司品牌、独立链接和介绍。
2. 项目管理中添加产品、设置产品大类，并创建多级文档分类。分类可调整父级和同级顺序，上移、下移和删除按钮就在左侧每个分类旁；产品文档列表同样支持上移 / 下移调整顺序，并同步到前台目录。
3. 共享内容使用“绑定已有文档”，可关联多个项目下的产品和分类。
4. 公司介绍、协议等差异内容使用“新建专属文档”或“复制为专属”。副本独立保存，修改不会影响原文档。
5. 文档中心统一编辑所有文档。编辑器组件用于插入提示框、代码、表格、流程图、公式等，预制样式控制主题和密度。
6. 保存草稿不会修改前台已发布版本；发布时可填写更新说明，并自动记录产品动态及当时的正文快照。

绑定已有已发布文档后，目标项目立即展示其已发布版本，尚未发布的草稿不会泄露。编辑器内修改绑定位置随下一次发布生效。共享文档发布后同步到所有绑定位置。

编辑器支持 Markdown 导入导出、图片插入与粘贴、撤销重做、分屏预览、全屏及快捷键。图片上传后使用短链接，前台支持点击放大；单张最大 10MB，正文最大 500 万字符。离开未保存内容会提示；过期编辑版本不能覆盖新版本。

产品可上传图片或视频（MP4 / WebM，最大 50MB），展示在产品概览右侧；未上传时保留默认插图。上传文件保存在 `data/uploads/`，通过 `/api/media/{文件名}` 读取，备份时应与 `data/store.json` 一起保留。

分类旁的加号可新增文章或子分类；点击分类后，左栏底部会出现该分类的编辑、上移、下移与删除菜单。使用文档操作列的“移动分类”，会立即调整当前产品中的位置。编辑器的“文档设置 → 项目绑定”中也可调整目录，发布后生效。

## 数据与兼容

`data/store.json` 保存项目产品目录、发布版本、草稿与更新历史。原有完整目录迁移为一个“中广云”项目，保留 24 个产品及原有分类；旧 `/docs/` 和旧项目文档链接自动跳转。迁移前备份：`.backups/before-project-hierarchy.json`。

已有发布内容作为历史基线收录，未保存过的更早修改记录无法补齐。新发布会保留真实版本快照。当前产品动态仅展示仍绑定在该产品的已发布文档历史。

数据通过临时文件与原子替换保存，适用于当前本地单服务使用方式。

## 验证

```sh
npm run typecheck
npm run build
TEST_BASE_URL=http://localhost:4000 npm run test:integration
TEST_BASE_URL=http://localhost:4000 npm run test:media
TEST_BASE_URL=http://localhost:4000 npm run test:reorder
```

集成测试创建独立临时项目与文档，验证多级分类、多项目复用、专属文档隔离、历史快照、草稿保护、过期保存冲突和删除保护，最后清理测试数据。

媒体与编辑器测试覆盖上传校验、媒体读取及分段请求、产品媒体设置、分类移动和共享文档隔离。

## 阅读与收藏

文档操作栏支持复制纯文字、复制 Markdown、收藏和二维码分享。收藏页 `/favorites` 显示收藏时间、取消按钮，并按每页 10 条分页。前台收藏无需登录，保存在当前浏览器中，不跨设备同步；后台管理使用独立的账号与角色权限。二维码采用当前访问域名生成；本地 localhost 链接仅供当前设备使用。

文档底部展示最近更新时间及当前产品目录顺序中的上一篇、下一篇。后台产品列表新增“管理产品分类”，支持创建空分类、重命名和删除空分类；新建或编辑产品可从分类下拉框选择。分类更新验证：`npm run test:groups`。

## 项目复制、变量与上下架

项目卡片的“复制项目”会打开可编辑名称与简介的表单，名称默认 `_副本`。复制时生成全新的项目、产品、分类与文档标识，保留分类层级、发布版本、独立草稿和历史；只保留副本项目内部绑定，不继续关联原项目。已有媒体文件使用不可变地址复用。

项目名称默认对应 `{{brand_name}}`，公司对应 `{{company_name}}`；项目表单可单独设置品牌名。文档地址可用同名查询参数覆盖显示值。`{{变量名|默认文字}}` 指定默认值；变量在当前项目既没有值也没有默认值时什么都不输出，若该行只剩这个变量就连整行一起省略（不留空白行），因此共享文档在未配置该变量的项目里不会露出占位符。代码块内只做替换、不删行。编辑器预览使用第一个绑定项目的上下文（文档绑定多个项目时可切换预览项目）。正文与副本内容保持模板原文。

产品分类、文档分类和文档均可上下架。分类下架会级联隐藏其子分类和内容；文档下架作用于该共享文档的所有绑定位置。保存/发布内容不会自动解除下架状态。公开页面、目录、搜索及接口统一过滤下架内容。

编辑器右栏包含标题、摘要、目录绑定和更新说明；工具栏提供标题级别、视频链接、分割线、上下标、附件、表格及媒体尺寸设置。媒体尺寸支持 `50%`、`640px`、`auto`；双栏容器内支持 Markdown 图片与视频。附件支持 PDF、TXT、MD、ZIP、DOCX、XLSX、PPTX（50MB），以下载方式读取。组件可通过 `:::styled {"className":"my-note","style":"padding:16px;background-color:#f5f7ff"}` 包装；类名引用项目已有样式，内联样式仅允许安全的排版属性。

## 内置大模型与展示编辑器组件

后台编辑器右侧组件栏新增“卡片与导航”和“AI与多模态”两大类，参考火山方舟官方文档视觉规范：

1. **导航卡片组 (`:::cards [cols=2|3|4]`)**：多列纯白卡片网格，支持卡片标题、外链/内部跳转与说明，用于快速入门、推荐应用与资源入口。
2. **特性亮点卡片 (`:::features [cols=2|3|4]`)**：火山蓝标题加要点圆点列表卡片网格，用于产品特性速览与版本更新亮点。
3. **提示词生图对比 (`:::prompt-preview`)**：两栏提示词与生成效果对比排版，内置一键复制提示词与大图放大查看。
4. **视频媒体网格 (`:::video-grid [cols=2|3|4]`)**：多列视频/图像输出矩阵，缩略图叠加半透明圆形播放按钮（`▶`），点击直接呼出视频弹窗播放器或大图预览。
5. **多模态生成展示 (`:::multimodal`)**：专为多模态生成的左右分栏容器，左栏承载输入图片与提示词引用块，右栏承载生成媒体矩阵（支持直接嵌套 `:::video-grid`）。
6. **分镜脚本展示 (`:::storyboard`)**：分镜与素材联动容器，左栏展示带行号的文本脚本（支持“Plain”标识与一键复制），右栏展示故事板分镜大图（蓝框高亮）与底部横向参考素材缩略图条。
7. **关键帧序列画廊 (`:::keyframes [cols=3|4|5]`)**：时序生成展示容器，顶部展示蓝色圆点引导的提示词示例，下方展示自适应关键帧序列图像矩阵。
8. **附件下载卡片 (`:::file [文件名](链接) [大小]`)**：紧凑型文件下载卡片，支持文档类型图标、名称截断与下载交互。
