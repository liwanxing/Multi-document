# Multi-document 改造 · 简版需求

> 一页纸版本。细节版在《后端化需求与排期.md》，那本是给我干活用的，你可以不看。

## 这个项目是什么

公司内部的**文档管理后台**：维护多个项目的文档，发布出去给大家看。

现在的问题是：**所有数据存在一个 JSON 文件里**（相当于记在一张纸上）。数据一多就慢、会互相覆盖、没法多人用。

**要做的事就一件：把"一张纸"换成"真正的数据库（MySQL）"。** 功能不变，页面不变。

## 附：为什么不用 Java

现在的后端接口是 JS 写好的、能跑的。换数据库不需要重写它们，只换"存数据的方式"。用 Java = 全部重写一遍 = 时间翻倍。**这次改造 90% 是后端活，前端 60 多个文件一行不动。**
